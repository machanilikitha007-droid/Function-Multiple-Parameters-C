# Function with Multiple Parameters in C

This program demonstrates a function that accepts multiple parameters
and returns their total.

## File

multiple_parameters.c

## Concepts Used

- Function declaration
- Function parameters
- Function call
- Return value

## How to Run

gcc multiple_parameters.c -o multiple_parameters
./multiple_parameters

## Sample Output

Enter marks for three subjects: 80 75 90
Total Marks = 245
